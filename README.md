Datheon Machine Learning and Data Science Internship

This repository contains my completed projects as part of the Datheon Machine Learning and Data Science Virtual Internship.

Project 1: Iris Classification

Objective: Classify Iris flowers into three species using their flower measurements.

Dataset: Iris dataset containing sepal length, sepal width, petal length and petal width.

Technologies: Python, Pandas, Seaborn, Matplotlib, Scikit-learn, Jupyter Notebook

Work completed:

- Loaded and explored the Iris dataset
- Visualized relationships between flower features using a Seaborn pairplot
- Split the dataset into training and testing sets (80:20)
- Standardized features using StandardScaler
- Trained Logistic Regression and Decision Tree classifiers
- Evaluated accuracy, precision, recall and F1-score
- Visualized confusion matrices to compare model performance

- Project 2: NLP Sentiment Classification

Objective: Classify customer or movie reviews as positive or negative using text features.

Technologies: Python, Pandas, Scikit-learn, TF-IDF, NLP, Jupyter Notebook

Work completed:

- Text cleaning and preprocessing
- TF-IDF feature extraction
- Multinomial Naive Bayes and Logistic Regression
- Model evaluation and performance comparison
- Interactive sentiment prediction function
